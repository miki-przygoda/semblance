# CI, with every flyvis gate live: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A GitHub Actions workflow that runs every flyvis acceptance gate, with fixtures present and verified, on every PR and every push to `main`.

**Architecture:** Fixtures come from two pinned sources. The connectome JSON comes from the Springer supplementary zip, and the flyvis exports come from a private release tarball (`fixtures-1`). Both are verified file by file against a committed `ci/fixtures.sha256` by `ci/fetch-fixtures.sh`, which also works locally. The workflow then runs build, `SEMBLANCE_REQUIRE_FIXTURES=1` tests, clippy with `-D warnings` on pinned Rust 1.97, and the roundtrip check. A separate job checks that the workspace still builds on the declared MSRV, 1.85.

**Tech Stack:** bash (3.2-compatible: macOS ships 3.2), curl, unzip, tar, shasum, gh CLI, GitHub Actions (`actions/checkout`, `actions/cache` only), rustup.

**Spec:** `docs/superpowers/specs/2026-10-01-ci-design.md`

## Global Constraints

- **Zero external dependencies.** `Cargo.lock` contains exactly 8 packages, all `semblance*`. Nothing in this plan touches it.
- **Nothing under `ci/` is referenced by any crate.** It sits outside the workspace the way `tools/` does.
- **Commit style: plain imperative subject, no `feat:`/`fix:`/`chore:` prefixes.**
- **Do not run `cargo fmt`.** The repo is not rustfmt-clean (see `docs/project-outline/chore-and-fixes/`).
- **`data/` and `docs/project-outline/` are gitignored. Never `git add` them.**
- **Do not invest in `sim`.** Its warnings get scoped `#[allow]`s, not rewrites.
- **CI toolchain: `test` job pinned to Rust `1.97`; `msrv` job on `1.85`.** No `rust-toolchain.toml`.
- **Actions allowed: `actions/checkout@v4`, `actions/cache@v4`.** No third-party actions.
- **Creating the `fixtures-1` release requires the user's explicit confirmation** at the point it happens (Task 3, Step 3), even though this plan is approved.
- **`roundtrip` must read exactly `0.000000` for both distances.** It is matched as a literal string, never as a tolerance.
- Pinned values (verified 2026-10-01):
  - connectome JSON sha256 `e609438ef261f4d12bf12556f4edb7a898ca4720029f9b882868967e6a0bbc73`, 192,611 bytes
  - inside the Springer zip at `2023-03-04080C-Supplementary Data/Lappalainen_et_al_connectome_avg_filters.json`
  - `data/flyvis-build/` + `data/flyvis-stimuli/`: 19 files, ~49 MB

## Review Focus

1. **A pre-existing local fixture that differs from the manifest** (a deliberate re-export): the script must fail, name the file, and leave it untouched. It must never overwrite it. Pinned by Task 2, Step 6.
2. **Partially populated `data/`** (the JSON present but the exports missing, or one export file deleted): the script must fetch only what is missing and must not touch verified files. Pinned by Task 2, Step 7 and Task 3, Step 6.
3. **A silent skip in CI.** If `SEMBLANCE_REQUIRE_FIXTURES` is not set on the test step, or the fixtures land in the wrong directory, the gates pass while testing nothing. The `--nocapture` step's distribution table in the log is the evidence. Pinned by Task 4, Step 5 and Task 5, Step 3.
4. **macOS metadata in the tarball.** bsdtar can add `._*` AppleDouble files. Build the tarball with `COPYFILE_DISABLE=1` and check the listing. Pinned by Task 3, Step 2.
5. **bash 3.2 on macOS.** No associative arrays, no `mapfile`, and no `"${arr[@]}"` on empty arrays under `set -u`. The script uses newline-separated strings. Pinned by running every local test in Task 2 under `/bin/bash` (3.2).

- [ ] **Step 3: Write `ci/fetch-fixtures.sh`**

```bash
#!/usr/bin/env bash
# Fetch and verify the fixtures the flyvis acceptance gates read.
#
# Two sources, both pinned by ci/fixtures.sha256:
#   - the connectome JSON, from the Nature supplementary zip (Springer)
#   - flyvis's own exports (data/flyvis-build, data/flyvis-stimuli), from the
#     private release named in ci/fixtures-tag
#
# Fetches only what is missing. A file that exists but fails verification is
# never overwritten -- locally it may be a deliberate re-export -- and the
# script fails naming it. Written for bash 3.2 (macOS's /bin/bash).
#
# Design: docs/superpowers/specs/2026-10-01-ci-design.md
set -euo pipefail

repo="$(cd "$(dirname "$0")/.." && pwd)"
data="${SEMBLANCE_DATA_DIR:-$repo/data}"
manifest="$repo/ci/fixtures.sha256"
tag="$(tr -d '[:space:]' < "$repo/ci/fixtures-tag")"
asset="flyvis-fixtures.tar.gz"
json="flyvis-supplementary/Lappalainen_et_al_connectome_avg_filters.json"
springer="https://static-content.springer.com/esm/art%3A10.1038%2Fs41586-024-07939-3/MediaObjects/41586_2024_7939_MOESM3_ESM.zip"

say() { echo "fetch-fixtures: $*" >&2; }

missing=""
bad=""
total=0
while read -r want path; do
  [ -z "${path:-}" ] && continue
  total=$((total + 1))
  if [ ! -f "$data/$path" ]; then
    missing="$missing$path"$'\n'
  elif [ "$(shasum -a 256 "$data/$path" | cut -d' ' -f1)" != "$want" ]; then
    bad="$bad$path"$'\n'
  fi
done < "$manifest"

if [ -n "$bad" ]; then
  say "these fixtures exist but do not match ci/fixtures.sha256:"
  printf '%s' "$bad" | sed 's/^/  /' >&2
  say "not overwriting them. If they are a deliberate re-export, publish a new"
  say "fixtures tag and update ci/fixtures-tag and ci/fixtures.sha256 together."
  exit 1
fi

if [ -z "$missing" ]; then
  say "all $total fixtures present and verified in $data"
  exit 0
fi

tmp="$(mktemp -d)"
trap 'rm -rf "$tmp"' EXIT

if printf '%s' "$missing" | grep -qxF "$json"; then
  say "fetching the connectome JSON from the Nature supplementary zip"
  curl -fsSL --retry 3 -o "$tmp/supplementary.zip" "$springer"
  unzip -q -j "$tmp/supplementary.zip" "*/$(basename "$json")" -d "$tmp/supplementary"
  mkdir -p "$data/$(dirname "$json")"
  cp "$tmp/supplementary/$(basename "$json")" "$data/$json"
fi

if printf '%s' "$missing" | grep -vqxF "$json"; then
  say "fetching $asset from release $tag"
  (cd "$repo" && gh release download "$tag" --pattern "$asset" --dir "$tmp")
  mkdir "$tmp/x"
  tar -xzf "$tmp/$asset" -C "$tmp/x"
  for path in $missing; do
    [ "$path" = "$json" ] && continue
    if [ ! -f "$tmp/x/$path" ]; then
      say "$path is listed in ci/fixtures.sha256 but is not in $tag's $asset"
      exit 1
    fi
    mkdir -p "$data/$(dirname "$path")"
    cp "$tmp/x/$path" "$data/$path"
  done
fi

if ! (cd "$data" && shasum -a 256 -c --quiet "$manifest"); then
  say "verification failed after fetching"
  exit 1
fi
say "fetched $(printf '%s' "$missing" | grep -c .) of $total fixtures; all $total verified"
```

```yaml
# Every flyvis acceptance gate, with fixtures present and verified.
# Design: docs/superpowers/specs/2026-10-01-ci-design.md
name: CI

on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read

env:
  CARGO_TERM_COLOR: always

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      # Pinned, not stable: with -D warnings a new stable lint would turn CI
      # red with no change in the repo. Bumping this is a deliberate edit.
      - name: Install Rust 1.97
        run: |
          rustup toolchain install 1.97 --profile minimal --component clippy
          rustup override set 1.97

      - uses: actions/cache@v4
        with:
          path: |
            ~/.cargo/registry
            ~/.cargo/git
            target
          key: cargo-1.97-${{ hashFiles('Cargo.lock') }}

      - uses: actions/cache@v4
        with:
          path: data/flyvis-supplementary/Lappalainen_et_al_connectome_avg_filters.json
          key: connectome-json-e609438ef261f4d12bf12556f4edb7a898ca4720029f9b882868967e6a0bbc73

      - name: Fetch and verify fixtures
        env:
          GH_TOKEN: ${{ github.token }}
        run: ci/fetch-fixtures.sh

      - name: Build
        run: cargo build --workspace

      - name: Test, with every fixture required
        env:
          SEMBLANCE_REQUIRE_FIXTURES: "1"
        run: cargo test --workspace

      # The geometry gate exists to be read, not just passed. Its table in the
      # log is also the evidence that the fixture gates ran rather than skipped.
      - name: Moving-edge gate distribution
        env:
          SEMBLANCE_REQUIRE_FIXTURES: "1"
        run: cargo test -p semblance-flyvis moving_edge_offsets_match_flyvis_within_tolerance -- --nocapture

      - name: Clippy
        run: cargo clippy --workspace --all-targets -- -D warnings

      # Lossless means exactly zero, matched as a literal string.
      - name: Roundtrip is lossless
        run: |
          out="$(cargo run --quiet -- roundtrip)"
          echo "$out"
          grep -qF 'structural distance:  0.000000' <<<"$out"
          grep -qF 'behavioural distance: 0.000000' <<<"$out"

  msrv:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install Rust 1.85
        run: |
          rustup toolchain install 1.85 --profile minimal
          rustup override set 1.85

      - uses: actions/cache@v4
        with:
          path: |
            ~/.cargo/registry
            ~/.cargo/git
            target
          key: cargo-1.85-${{ hashFiles('Cargo.lock') }}

      - name: Build on the declared rust-version
        run: cargo build --workspace --all-targets
```
